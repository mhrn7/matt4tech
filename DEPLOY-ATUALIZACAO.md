# Publicar esta atualização

1. Extraia o ZIP.
2. No GitHub Desktop, selecione o repositório `matt4tech-new`.
3. Clique em **Repository → Show in Explorer**.
4. Copie todo o conteúdo da pasta `matt4-tech` extraída para a pasta do repositório e substitua os arquivos.
5. No GitHub Desktop, faça **Commit to main** e depois **Push origin**.
6. Na Vercel, abra **Settings → Environment Variables** e crie `RESEND_API_KEY` com uma chave ativa do Resend.
7. Marque Production, Preview e Development.
8. Confirme que `matt4tech.site` está verificado no Resend.
9. Faça um novo deploy sem usar o cache.
10. Envie um formulário real e confirme o recebimento em `contact@matt4tech.site` e `contact.elevaimkt@gmail.com`.

A chave do Resend nunca deve ser colocada dentro dos arquivos ou enviada ao GitHub.
